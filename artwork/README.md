# Artwork image folder

Place approved web exports here. Use lowercase, descriptive filenames such as
`untitled-red-field-2025.webp`.

Recommended master web export:

- WebP or AVIF
- 2,400 px on the longest edge
- sRGB color profile
- 80–88% quality
- No watermark unless Chris explicitly requests one

Artwork files are ignored by Git by default until image rights, filenames, and
the publishing approach are confirmed.
